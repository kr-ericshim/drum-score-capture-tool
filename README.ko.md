# Drum Sheet Capture 사용 가이드

영상에 표시된 악보 영역을 캡처해 PNG·JPG·PDF로 저장하는 데스크톱 앱입니다. 오디오를 듣고 악보를 만드는 채보 프로그램은 아니며, MusicXML·MIDI 변환은 지원하지 않습니다.

[최신 릴리즈 다운로드](https://github.com/kr-ericshim/drum-score-capture-tool/releases/latest) · [프로젝트 홈](./README.md) · [English](./README.en.md)

이 가이드는 현재 소스 기준입니다. 아직 배포되지 않은 기능은 설치된 버전과 다를 수 있으므로 해당 릴리즈의 변경 내역을 함께 확인하세요.

## 설치

| 환경 | 받을 파일 |
| --- | --- |
| Windows x64 — Intel/AMD 64비트 | `.exe` 설치 파일 |
| macOS Apple Silicon — M 시리즈 | `arm64.dmg` |

Python·Node.js·FFmpeg를 따로 설치할 필요가 없습니다. Intel Mac, Windows ARM64 네이티브, Linux 설치 파일은 현재 제공하지 않습니다.

### Windows

1. 위 릴리즈 페이지의 **Assets**에서 `.exe`를 받습니다. 소스 코드 ZIP은 설치 파일이 아닙니다.
2. 설치 프로그램을 실행하고 앱을 엽니다.
3. 현재 빌드는 서명되지 않아 SmartScreen 경고가 나타날 수 있습니다. 이 저장소에서 받은 파일인지 확인한 후, 화면에 제공되는 `추가 정보 → 실행`으로 진행할 수 있습니다. 조직에서 관리하는 PC는 실행 정책이 다를 수 있습니다.

### macOS

1. **Assets**에서 `arm64.dmg`를 받습니다.
2. DMG를 열고 앱을 `Applications` 폴더로 복사합니다.
3. 복사한 앱을 실행합니다.

현재 빌드는 서명·공증되지 않아 Gatekeeper가 실행을 막을 수 있습니다. 이 저장소에서 받은 파일임을 확인한 후, 터미널에서 설치한 앱의 격리 속성을 제거하고 다시 실행합니다.

```bash
xattr -dr com.apple.quarantine "/Applications/Drum Sheet Capture.app"
```

DMG 자체가 열리지 않는 경우에는 아래 경로를 실제 다운로드한 DMG 경로로 바꿔 적용합니다. 따옴표는 유지하세요.

```bash
xattr -dr com.apple.quarantine "/실제/다운로드/경로/다운로드한파일.dmg"
```

## 기본 사용 흐름

1. **영상 가져오기:** 로컬 영상 파일을 선택하거나 공개 YouTube 주소를 입력해 영상을 준비합니다.
2. **악보 영역 지정:** 악보가 선명한 프레임을 열고 추천된 영역(ROI)을 확인·수정합니다. 추천이 없으면 직접 영역을 지정합니다. 추천은 초안이므로 **영역 적용**을 눌러야 확정됩니다. 음표·가사·반복 기호가 잘리지 않도록 여백을 확인합니다.
3. **캡처 실행:** 처리 구간과 저장 형식을 확인한 뒤 캡처를 시작합니다.
4. **결과 검토:** 페이지를 확인하고 필요한 캡처를 선택합니다. 필요한 경우 검토 화면에서 자르기와 선택 결과를 반영해 PDF를 다시 만듭니다.
5. **파일 저장:** PNG·JPG·PDF 결과를 확인합니다. `PDF 다른 이름으로 저장…`으로 보관할 위치에 PDF 복사본을 저장할 수 있습니다.

저장된 언어 설정이 있으면 그 값을 사용합니다. 없으면 시스템 언어가 한국어일 때 한국어, 그 외에는 영어로 시작합니다.

## 입력·저장 안내

- 영상 처리는 로컬에서 실행됩니다. YouTube 가져오기에는 인터넷 연결이 필요합니다.
- 로그인·연령·지역 제한 또는 YouTube 측 변경으로 일부 링크는 가져오지 못할 수 있습니다. 로컬 영상으로도 처리할 수 있습니다.
- 로컬 파일 선택에서 지원하는 확장자는 MP4, MKV, MOV, AVI, WEBM입니다. 확장자가 같아도 손상된 파일이나 일부 코덱은 읽지 못할 수 있습니다.
- 작업 중 영상·프레임·결과 파일이 쌓이므로 설치 파일보다 사용 중 디스크 점유가 커질 수 있습니다. 중요한 PDF는 원하는 폴더에 별도 저장하세요.
- 기본 작업 데이터는 설치된 앱의 사용자 데이터 폴더 아래 `jobs`에 저장됩니다. 개발 실행은 `backend/jobs`를 사용합니다.

## 문제 해결

| 증상 | 먼저 확인할 내용 |
| --- | --- |
| 백엔드 연결 실패 | 앱을 완전히 종료한 뒤 다시 열고, OS 아키텍처에 맞는 최신 설치본인지 확인합니다. 계속 실패하면 오류 메시지와 앱 버전을 기록합니다. |
| YouTube 가져오기 실패 | 공개 링크인지 확인하고 세부 진행 로그를 확인합니다. 로컬 영상 입력도 시도합니다. |
| 프레임이 흐리거나 잘못된 장면 | 악보가 정지해 선명하게 보이는 시점으로 옮겨 프레임을 다시 불러옵니다. |
| 음표나 악보 가장자리가 잘림 | 원본 프레임에서 ROI를 다시 조정한 뒤 재실행합니다. PDF를 확대해 위아래 기호까지 확인합니다. |
| 결과 페이지가 예상과 다름 | 검토 화면에서 누락·중복·의심 캡처를 확인하고 최종 선택으로 다시 내보냅니다. |

해결되지 않으면 [Issues](https://github.com/kr-ericshim/drum-score-capture-tool/issues)에 앱 버전, OS와 CPU 종류, 로컬/YouTube 입력 여부, 재현 순서, 오류 메시지를 남겨 주세요. 로그의 개인 경로나 비공개 링크는 지워 주세요.
