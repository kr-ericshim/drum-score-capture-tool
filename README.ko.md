# Drum Sheet Capture 사용 가이드

영상에 이미 나오는 드럼 악보를 모아 A4 PDF로 만드는 앱입니다. 악보 영역을 정하면 영상에 나온 악보 줄을 읽어, 원본 악보 이미지를 깨끗하게 정리한 뒤 마디 단위로 A4에 다시 배치합니다. PNG·JPG로도 저장할 수 있습니다.

소리를 듣고 악보를 만드는 채보, 음표 인식, MusicXML·MIDI 변환 기능은 없습니다.

[설치 파일 다운로드](https://github.com/kr-ericshim/drum-score-capture-tool/releases/latest) · [프로젝트 홈](./README.md) · [English](./README.en.md)

이 문서는 v0.3.0 기준입니다. v0.2.1 이하 설치 파일은 악보 화면을 페이지 이미지로 캡처하는 이전 방식이라 화면과 결과가 다릅니다. 설치한 버전의 기능은 [릴리스 노트](https://github.com/kr-ericshim/drum-score-capture-tool/releases)를 확인하세요.

## 지원하는 영상

| 영상 | 상태 |
| --- | --- |
| 불투명한 판(밝거나 어두운 배경) 위에 **악보 한 줄**이 나오고, 그 줄이 통째로 다음 줄로 바뀌는 영상 | 지원 |
| 같은 줄 안에서 화면이 옆으로 넘어가는 영상(점프) | 실험 기능. 앱이 추정해 이은 곳은 검토 화면의 **이음새 확인**에서 영상과 비교해야 합니다. |
| 반투명 판이나 움직이는 영상 위에 겹쳐 그린 악보 | 처리하지 않고 지원하지 않는다고 알립니다. |
| 악보가 옆으로 흐르거나 여러 줄이 함께 위로 스크롤되는 영상 | 처리하지 않고 지원하지 않는다고 알립니다. |
| 여러 줄이 한 페이지로 나오는 영상, 세로로 길게 내려가는 악보 | 범위 밖. 결과를 보장하지 않습니다. |

0.5초보다 짧게 스쳐 간 화면은 놓칠 수 있습니다. 연주 전에 PDF를 영상과 한 번 비교해 보세요.

## 설치

다운로드 페이지의 **Assets**에서 컴퓨터에 맞는 파일을 받으세요. `Source code` ZIP은 설치 파일이 아닙니다.

| 컴퓨터 | 받을 파일 |
| --- | --- |
| Windows — Intel/AMD 64비트 | `.exe` |
| Mac — Apple Silicon(M 시리즈), macOS 13(Ventura) 이상 | `arm64.dmg` |

설치 파일에 실행에 필요한 구성 요소가 들어 있어 Python, Node.js, FFmpeg를 따로 설치하지 않아도 됩니다. Intel Mac, Windows ARM64 전용, Linux 설치 파일은 제공하지 않습니다.

### Windows

`.exe`를 실행해 설치한 뒤 Drum Sheet Capture를 여세요.

설치 파일에 코드 서명이 없어 SmartScreen 경고가 나올 수 있습니다. 위 저장소에서 받은 파일이 맞다면 **추가 정보 → 실행**으로 진행할 수 있습니다. 회사나 학교에서 관리하는 PC에서는 이 버튼이 없거나 실행이 제한될 수 있습니다.

### macOS

DMG를 열고 **Drum Sheet Capture.app**을 **Applications(응용 프로그램)** 폴더로 옮긴 뒤 실행하세요.

macOS 앱에는 무료 ad-hoc 서명만 있고 Apple Developer ID 서명과 공증은 없으므로 처음 실행할 때 macOS가 차단할 수 있습니다. 공식 저장소에서 받은 앱인지 확인한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**를 선택하세요. 관리되는 Mac에서는 실행이 제한될 수 있습니다.

설정에서 허용할 수 없는 경우에만, 출처를 확인한 설치 앱에 한해 아래 명령으로 다운로드 격리 속성을 제거한 뒤 다시 여세요. 이 명령은 서명 오류를 복구하지 않습니다.

```bash
xattr -dr com.apple.quarantine "/Applications/Drum Sheet Capture.app"
```

계속 “손상됨”이 표시되면 보안 기능을 전체 해제하지 말고 최신 설치본을 다시 받거나 문제를 알려 주세요.

macOS 12를 쓰고 있다면 v0.1.37을 계속 쓰고 앱 안의 업데이트를 누르지 마세요. v0.2.0부터 macOS 13 이상이 필요합니다.

## 사용법

왼쪽의 **영상 선택 → 악보 영역 → 파일 만들기 → 검토 · 저장** 순서로 진행합니다. 화면이 영어로 나오면 왼쪽 아래에서 **KO**를 선택하세요. 언어 설정은 다음 실행에도 유지됩니다.

### 1. 영상 선택

컴퓨터에 있는 영상은 **파일 열기**로 선택하거나 화면에 끌어 놓으세요. MP4, MKV, MOV, AVI, WEBM 파일을 열 수 있습니다. 파일 선택 창은 지난번에 연 폴더에서 열립니다.

YouTube 영상은 주소를 붙여 넣고 Enter나 **유튜브 영상 준비**를 누르세요. 준비가 끝나면 다음 단계로 넘어갑니다. 자세한 진행은 **세부 진행**에서 볼 수 있습니다.

전에 쓴 영상은 **다시 열기** 목록에서 열 수 있습니다. 원본 파일을 옮기거나 지웠다면 다시 선택해야 합니다. 영상을 고르면 파일명·해상도·길이와 **다음: 악보 영역** 버튼이 나옵니다.

### 2. 악보 영역

악보가 선명하게 보이는 장면에서 악보 영역을 정합니다.

1. **대표 프레임**의 앞쪽·추천·뒤쪽 중 적당한 장면을 고릅니다. 다른 장면을 보려면 **시점** 슬라이더를 옮긴 뒤 **현재 시점 다시 보기**를 누르세요.
2. 자동으로 추천된 영역을 확인하고, 맞지 않으면 영역이나 모서리를 끌어 조절합니다. 추천이 없으면 직접 그리세요.
3. 음표, 가사, 반복 기호가 잘리지 않았는지 확인한 뒤 **영역 적용**을 누릅니다. **적용하고 PDF 만들기**를 누르면 바로 PDF 만들기를 시작합니다.

자동 추천은 고칠 수 있는 초안이고, **영역 적용**을 눌러야 확정됩니다. 직접 고친 영역은 늦게 도착한 추천으로 바뀌지 않습니다. 적용 후 다시 고쳤다면 **영역 적용**을 한 번 더 누르세요.

- **흰 악보 배경 자동 맞춤**: 지정한 범위 안에서 흰 악보 배경의 경계가 확실할 때만 맞춥니다. 애매하면 지정한 범위를 그대로 둡니다.
- **구간 표시 영역 추가**: 악보 영역 밖에 구간 이름(예: Verse, A, B)이 그려진 영상이면, 그 이름을 감싸는 영역을 따로 지정할 수 있습니다. 글자를 다시 쓰지 않고 원본 이미지 그대로 해당 줄 위에 넣습니다.
- 적용하면 영상 전체에서 악보가 영역 밖으로 나가는지 확인합니다. 위아래가 잘린다는 안내가 나오면 **추천 영역 사용**으로 더 넓은 영역을 초안으로 불러올 수 있습니다.

### 3. 파일 만들기

필요하면 **캡처 구간**의 **시작**·**종료**를 입력하세요. `1:30`처럼 분:초나 `90`처럼 초로 씁니다. 두 칸을 비우면 전체 영상, 시작만 쓰면 그 시점부터 끝까지 처리합니다.

**PDF 만들기**를 누르면 정보 창 없이 바로 시작합니다. 제목은 영상 이름에서 자동으로 채워집니다. 제목·연주자·BPM·날짜·메모를 넣으려면 먼저 **PDF 정보 수정…**을 누르세요. 문서 정보는 PDF 첫 페이지에 들어갑니다.

PNG·JPG가 필요하면 **자세히**를 열어 **PNG 묶음**, **JPG 묶음**을 고르세요. PDF와 같은 페이지 구성으로 만들어집니다.

처리 중에는 진행 상황을 볼 수 있고 **작업 취소**로 멈출 수 있습니다. 끝나면 알림이 뜹니다. **검토 · 저장**에서 결과를 확인하세요.

### 4. 검토 · 저장

왼쪽 목록에는 PDF에 들어갈 **악보 줄**이 순서대로 있습니다. 줄을 누르면 크게 보고, 체크박스로 **출력에 포함** 여부를 정합니다. 배경색은 지금 보는 줄, 체크박스는 포함 여부만 뜻합니다.

- **위로 / 아래로**: 줄 순서를 바꿉니다. 기본 순서는 영상에 나온 순서이고, 반복이나 D.S.로 앞 줄이 다시 나오면 다시 넣습니다.
- **비슷해 보임**: 앞에서 나온 줄과 비슷한 줄입니다. **나란히 비교**로 확인하고, 같은 줄이 중복된 것이면 **이 줄 빼기**를 누르세요. 반복 구간이면 그대로 둡니다.
- **짧은 전환 화면 (N)**, **다른 순간 (N)**: 잠깐만 보인 화면이나 표시입니다. 체크 해제된 채 목록에 있고, 체크한 것만 악보에 들어갑니다.
- **A4 보기 / 줄 보기**: 마지막으로 만든 페이지 모양과 줄 하나씩 보기를 오갑니다.
- **마디 단위로 다시 배치 (한 줄 약 4마디)**: 기본으로 켜져 있습니다. 끄면 영상에 보인 줄 그대로 배치합니다.
- **확인 필요**, **미완성**: 원본에서 잘린 부분이나 구분이 어려운 표시, 악보를 찾지 못한 구간이 있다는 뜻입니다. 안내된 줄과 구간을 영상과 비교하세요.
- **이음새 확인**(점프 영상): 앱이 추정해 이은 곳마다 영상을 재생하며 확인합니다. **마디가 겹치거나 빠졌어요**를 고르고 다시 만들면 그곳은 잇지 않고 앞뒤 화면을 모두 남깁니다.
- 페이지에 들어가지 않는 줄이 있으면 그 줄을 빼거나 **이 문서만 N mm로 만들기**로 악보 크기를 줄입니다.

바꾼 내용은 **PDF 다시 만들기**를 눌러야 파일에 반영됩니다. 다시 만들 때는 영상을 다시 캡처하지 않습니다. **제목 수정**으로 PDF 제목만 바꿔 다시 만들 수도 있습니다.

결과는 **PDF 열기**로 확인하고, 아이콘 버튼의 **PDF 다른 이름으로 저장…**으로 원하는 폴더에 보관하세요. 저장 창은 지난번 폴더에서 열립니다. PNG·JPG는 **결과 폴더 열기**에서 복사합니다. 다음 곡은 **다른 영상 열기**로 바로 시작할 수 있습니다.

## 결과물

### clean reflow (기본)

영상에 나온 악보 줄을 모아 영상 배경과 재생 표시를 지우고, 원본 악보 이미지 그대로 마디 경계에서 줄을 나눠 A4 폭에 맞춥니다. 음표를 다시 그리지 않으며, 구간 표시·템포·가사 같은 악보 글자도 원본 이미지로 남깁니다. 원본 해상도가 낮으면 선명도도 그만큼입니다.

### 원본 화면 (대안)

정리된 결과가 이상하면 검토 화면 아래의 **결과가 이상하면 원본 화면으로 다시 만들기**를 누르세요. 영상 화면을 손대지 않고 그대로 담아 PDF를 만듭니다. 같은 부분이 반복될 수 있습니다. 악보가 한 줄씩 나오는 영상에서만 쓸 수 있으며, 원본 이미지는 **원본 이미지 폴더 열기**에서 볼 수 있습니다.

## 저장한 PDF 다시 열기

왼쪽 아래 **보관함**에서 영상별로 마지막에 만든 PDF를 찾을 수 있습니다. 항목을 고르면 **PDF 열기**, **폴더 열기**, **소스 다시 열기**를 쓸 수 있습니다.

보관함은 앱 작업 폴더에 있는 파일을 보여 줄 뿐 백업이 아닙니다. 보관할 PDF는 **PDF 다른 이름으로 저장…**으로 원하는 곳에 복사해 두세요. PNG·JPG만 만든 작업은 보관함에 나오지 않습니다.

## 앱 저장 공간 비우기

**보관함 → 캐시 비우기**에서 사용 중인 공간을 보고 정리할 수 있습니다. 확인 창의 **모두 지우기**를 눌러야 삭제됩니다.

**앱 작업 폴더의 캡처, 만든 PDF·이미지, YouTube로 받은 영상, 보관함·최근 영상 기록이 삭제됩니다.** 원본 로컬 영상과 **PDF 다른 이름으로 저장…**으로 따로 보관한 파일은 남습니다. 삭제는 되돌릴 수 없으며, 작업이 진행 중일 때는 비울 수 없습니다.

## 단축키

| 화면 | 키 | 동작 |
| --- | --- | --- |
| 악보 영역 | `Tab` | 영역 편집 칸으로 이동 |
| 악보 영역 | 방향키 | 영역 이동 |
| 악보 영역 | `1`–`4` | 조절할 모서리 선택 |
| 악보 영역 | `0` | 영역 전체 이동으로 전환 |
| 악보 영역 | `Shift` + 방향키 | 더 크게 조절 |
| 검토 · 저장 | `←` / `→` | 이전 / 다음 줄 |
| 검토 · 저장 | `Space` | 보고 있는 줄 포함 / 제외 |
| 검토 · 저장 | `Ctrl+Z` / `⌘Z` | 되돌리기 |
| 검토 · 저장 | `Ctrl+Shift+Z` / `⌘Shift+Z` | 다시 실행 |

영역 편집 단축키는 편집 칸에 포커스가 있을 때 작동합니다. 검토 단축키는 입력란에서는 작동하지 않으며, 버튼에 포커스가 있으면 Space는 그 버튼을 누릅니다.

## 알아둘 점

- 영상 처리는 컴퓨터에서 실행됩니다. YouTube 영상을 가져올 때는 인터넷 연결이 필요합니다.
- 설치형 앱은 실행할 때와 **업데이트** 버튼을 누를 때 GitHub에서 새 버전을 확인합니다. **업데이트**를 눌러야 내려받고, 체크섬을 확인한 뒤 **재시작하여 설치**를 누르면 설치합니다. macOS에서 앱을 직접 바꿀 수 없는 위치(DMG 안, 쓰기 권한이 없는 폴더)에서 실행 중이면 설치 창을 열어 줍니다.
- **문제 보고**는 **보내기**를 누를 때만 적은 내용과, 선택한 진단 로그·앱 화면 스크린샷을 개발자에게 보냅니다. 영상과 만든 파일은 보내지 않습니다. 스크린샷에는 화면에 보이는 악보가 함께 담깁니다.
- 로그인·연령·지역 제한이 있거나 YouTube의 동작이 바뀌면 일부 영상을 가져오지 못할 수 있습니다.
- 지원 확장자라도 파일이 손상됐거나 코덱을 읽을 수 없으면 열리지 않을 수 있습니다.
- 영상과 중간 파일이 쌓이므로 사용 중 필요한 디스크 공간은 설치 용량보다 큽니다.
- 작업 데이터는 설치된 앱의 사용자 데이터 폴더 아래 `jobs`에 저장됩니다. 소스로 개발 실행할 때는 `backend/jobs`를 씁니다.

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| 처리기에 연결되지 않음 | 앱을 완전히 종료하고 다시 실행하세요. 계속 실패하면 **진단 로그 복사**로 로그를 남겨 알려 주세요. |
| YouTube 가져오기 실패 | 공개 영상인지 확인하고 **세부 진행**의 오류를 보세요. 같은 영상을 파일로 갖고 있다면 **파일 열기**로 시도하세요. |
| 해상도 부족 안내 | 더 높은 해상도의 영상이나 원본 파일을 쓰세요. |
| 지원하지 않는 영상이라고 나옴 | [지원하는 영상](#지원하는-영상)을 확인하세요. 반투명 판·겹쳐 그린 악보, 옆으로 흐르거나 함께 스크롤되는 악보는 처리하지 않습니다. |
| 영역 안에서 악보 줄을 찾지 못함 | **악보 영역**으로 돌아가 오선 전체가 들어가게 다시 적용하세요. |
| 음표나 기호가 잘림 | **악보 영역**에서 범위를 넓혀 적용한 뒤 다시 만드세요. 이미 잘린 부분은 검토 화면에서 되살릴 수 없습니다. |
| 줄이 빠지거나 두 번 나옴 | 검토 화면의 **확인 필요**·**미완성**·**비슷해 보임**을 확인하고, 줄을 고친 뒤 **PDF 다시 만들기**를 누르세요. 한 줄씩 나오는 영상이면 원본 화면으로 다시 만들 수도 있습니다. |
| PDF에 바꾼 내용이 없음 | **PDF 다시 만들기**를 누른 뒤 **PDF 열기**로 새 파일을 여세요. |
| 보관함에 결과가 없음 | PDF를 만든 작업인지, 작업 폴더의 PDF를 옮기거나 지우지 않았는지 확인하세요. |

해결되지 않으면 앱의 **문제 보고**나 [Issues](https://github.com/kr-ericshim/drum-score-capture-tool/issues)에 앱 버전, 운영체제와 CPU 종류, 사용한 영상(주소 또는 종류), 문제가 생긴 순서, 오류 메시지를 남겨 주세요. GitHub 이슈는 누구나 볼 수 있으니 로그의 개인 파일 경로나 비공개 링크는 지우고 올려 주세요.
