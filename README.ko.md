# Drum Sheet Capture 사용 가이드

영상 속 악보를 캡처해 PNG, JPG, PDF로 저장하는 앱입니다. 악보가 나오는 부분을 지정하면 캡처한 이미지를 모아 파일로 만듭니다. 저장 전에 중복된 캡처를 빼거나 여백을 자를 수 있습니다.

소리를 듣고 악보를 만드는 채보 기능이나 MusicXML·MIDI 변환 기능은 없습니다.

[설치 파일 다운로드](https://github.com/kr-ericshim/drum-score-capture-tool/releases/latest) · [프로젝트 홈](./README.md) · [English](./README.en.md)

이 문서는 v0.1.32 소스를 기준으로 작성했습니다. 설치한 버전이 다르면 버튼 이름이나 화면 구성이 다를 수 있습니다.

## 설치

다운로드 페이지의 **Assets**에서 컴퓨터에 맞는 파일을 받으세요. `Source code` ZIP은 설치 파일이 아닙니다.

| 컴퓨터 | 받을 파일 |
| --- | --- |
| Windows — Intel/AMD 64비트 | `.exe` |
| Mac — Apple Silicon(M 시리즈) | `arm64.dmg` |

설치 파일에 실행에 필요한 구성 요소가 들어 있어 Python, Node.js, FFmpeg를 따로 설치하지 않아도 됩니다. Intel Mac, Windows ARM64 전용, Linux 설치 파일은 제공하지 않습니다.

### Windows

`.exe`를 실행해 설치한 뒤 Drum Sheet Capture를 여세요.

설치 파일에 코드 서명이 없어 SmartScreen 경고가 나올 수 있습니다. 위 저장소에서 받은 파일이 맞다면 **추가 정보 → 실행**으로 진행할 수 있습니다. 회사나 학교에서 관리하는 PC에서는 이 버튼이 없거나 실행이 제한될 수 있습니다.

### macOS

DMG를 열고 **Drum Sheet Capture.app**을 **Applications(응용 프로그램)** 폴더로 옮긴 뒤 실행하세요.

앱에 코드 서명과 공증이 없어 macOS가 실행을 막을 수 있습니다. 위 저장소에서 받은 앱이 맞다면 터미널에서 다음 명령을 실행하고 앱을 다시 여세요. 설치한 앱의 격리 속성을 제거하는 명령입니다.

```bash
xattr -dr com.apple.quarantine "/Applications/Drum Sheet Capture.app"
```

DMG 자체가 열리지 않으면 아래 경로를 실제 다운로드한 DMG 경로로 바꿔 실행하세요. 경로를 감싼 따옴표는 그대로 둡니다.

```bash
xattr -dr com.apple.quarantine "/실제/다운로드/경로/다운로드한파일.dmg"
```

## 사용법

상단의 **영상 선택 → 악보 영역 → 파일 만들기 → 검토 · 저장** 순서로 진행합니다. 화면이 영어로 나오면 상단에서 **KO**를 선택하세요. 언어 설정은 다음 실행에도 유지됩니다.

### 1. 영상 선택

컴퓨터에 있는 영상은 **파일 열기**로 선택하거나 파일을 화면에 끌어 놓으세요. MP4, MKV, MOV, AVI, WEBM 파일을 선택할 수 있습니다.

YouTube 영상은 주소를 붙여 넣고 **유튜브 영상 준비**를 누르세요. 다운로드와 준비가 끝난 뒤 다음 단계로 이동합니다. 진행 상황은 **유튜브 준비 상태**, 자세한 로그는 **세부 진행**에서 확인할 수 있습니다.

이전에 사용한 영상은 아래 **다시 열기** 목록에서도 열 수 있습니다. 로컬 원본 파일을 옮기거나 지웠다면 파일을 다시 선택해야 합니다.

### 2. 악보 영역

악보가 선명하게 보이는 장면에서 캡처할 범위를 정합니다.

1. **대표 프레임**의 앞쪽·추천·뒤쪽 중 적당한 장면을 고릅니다. 다른 장면을 보고 싶으면 **시점** 슬라이더를 옮긴 뒤 **현재 시점 다시 보기**를 누르세요.
2. 자동으로 추천된 영역을 확인하고, 맞지 않으면 마우스로 영역이나 모서리를 조절합니다. 추천 영역이 없으면 직접 그리세요.
3. 음표, 가사, 반복 기호가 잘리지 않았는지 확인한 뒤 **영역 적용**을 누릅니다.

자동 추천만으로 영역이 확정되지는 않습니다. 직접 수정한 영역은 뒤늦게 도착한 추천으로 바뀌지 않습니다. 적용 후 영역을 다시 수정했다면 **영역 적용**을 한 번 더 눌러야 합니다.

**흰 악보 배경 자동 맞춤**은 지정한 범위 안에서 흰 악보 배경의 경계를 찾아 맞추는 옵션입니다. 경계가 뚜렷하지 않으면 지정한 범위를 유지합니다.

여기서 고르는 시점은 영역을 확인할 장면입니다. 캡처 시작·종료 시점을 정하는 기능은 아니며, 현재 화면에서는 영상 전체를 처리합니다.

### 3. 파일 만들기

미리보기를 확인하고 **PDF 문서**, **PNG 묶음**, **JPG 묶음** 중 필요한 형식을 선택하세요. 여러 형식을 함께 선택할 수 있습니다.

- **PDF를 선택한 경우:** **다음: PDF 정보 입력**을 누릅니다. 제목을 확인하고 필요한 연주자·BPM·날짜·메모를 입력한 뒤 **PDF 생성 시작**을 누르세요. 제목은 필수이고, BPM을 입력한다면 숫자만 쓸 수 있습니다. 문서 정보는 PDF 첫 페이지에 들어갑니다.
- **이미지만 선택한 경우:** **출력 생성 시작**을 누릅니다.

파일은 앱이 관리하는 작업 폴더에 만들어집니다. 처리 중에는 진행 상황을 볼 수 있고, **작업 취소**로 중단할 수 있습니다.

### 4. 검토 · 저장

캡처 목록에서 하나를 누르면 크게 볼 수 있습니다. **지금 보고 있는 캡처**와 **출력에 포함할 캡처**는 별개입니다. 목록의 **포함** 체크나 미리보기의 **이 캡처 제외 / 다시 포함**으로 출력 여부를 정하세요.

- **확인 필요**를 누르면 확인이 필요한 것으로 표시된 캡처만 모아 볼 수 있습니다. 이 표시는 참고용이므로 누락이나 중복은 직접 확인하세요.
- 여백을 줄이려면 **자르기**를 누르고 범위를 조절한 뒤 **자르기 적용**을 누르세요. **자르기 초기화**로 되돌릴 수 있습니다.
- 선택이나 자르기를 바꿨다면 **PDF 다시 만들기**를 누르세요. 이미지만 출력하는 작업에서는 **이미지 다시 만들기**로 표시됩니다.

**선택 저장됨**을 확인한 뒤 **저장된 PDF 열기** 또는 **결과 폴더 열기**로 결과를 확인하세요. PDF를 다른 폴더에 보관하려면 **PDF 다른 이름으로 저장…**을 누릅니다. PNG·JPG는 결과 폴더에서 복사하면 됩니다.

**다시 만들기 전에는 수정 내용이 기존 출력 파일에 반영되지 않습니다.** 버튼이 **이전 PDF 열기**나 **이전 PDF 다른 이름으로…**로 표시된다면, 마지막으로 만든 PDF를 여는 상태입니다. 수정한 결과를 저장하려면 먼저 PDF를 다시 만드세요.

## 저장한 PDF 다시 열기

상단의 **보관함**에서 영상별로 마지막에 만든 PDF를 찾을 수 있습니다. 항목을 선택하면 **PDF 열기**, **폴더 열기**, **소스 다시 열기**를 사용할 수 있습니다.

보관함은 앱의 작업 폴더에 있는 파일을 보여줍니다. 별도 백업은 아니므로 보관할 PDF는 **PDF 다른 이름으로 저장…**으로 원하는 위치에 복사해 두세요. PNG·JPG만 만든 작업은 PDF 보관함에 나오지 않습니다.

## 단축키

| 화면 | 키 | 동작 |
| --- | --- | --- |
| 악보 영역 | `Tab` | 영역 편집 칸으로 이동 |
| 악보 영역 | 방향키 | 영역 이동 |
| 악보 영역 | `1`–`4` | 조절할 모서리 선택 |
| 악보 영역 | `0` | 영역 전체 이동으로 전환 |
| 악보 영역 | `Shift` + 방향키 | 더 크게 조절 |
| 검토 · 저장 | `←` / `→` | 이전 / 다음 캡처 |
| 검토 · 저장 | `Space` | 보고 있는 캡처 포함 / 제외 |
| 검토 · 저장 | `Ctrl+Z` / `⌘Z` | 되돌리기 |
| 검토 · 저장 | `Ctrl+Shift+Z` / `⌘Shift+Z` | 다시 실행 |

영역 편집 단축키는 편집 칸에 포커스가 있을 때 작동합니다. 검토 단축키는 입력란이나 자르기 편집 창에서는 작동하지 않으며, 버튼에 포커스가 있으면 Space는 해당 버튼을 누릅니다.

## 알아둘 점

- 영상 처리는 컴퓨터에서 실행됩니다. YouTube 영상을 가져올 때는 인터넷 연결이 필요합니다.
- 로그인·연령·지역 제한이 있거나 YouTube의 동작이 바뀌면 일부 영상을 가져오지 못할 수 있습니다.
- 지원 확장자라도 파일이 손상됐거나 코덱을 읽을 수 없으면 열리지 않을 수 있습니다.
- 영상, 미리보기, 캡처 파일이 쌓이므로 사용 중 필요한 디스크 공간은 설치 용량보다 큽니다.
- 기본 작업 데이터는 설치된 앱의 사용자 데이터 폴더 아래 `jobs`에 저장됩니다. 소스로 개발 실행할 때는 `backend/jobs`를 사용합니다.

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| 처리기에 연결되지 않음 | 앱을 완전히 종료하고 다시 실행하세요. 계속 실패하면 앱 버전과 오류 메시지를 기록해 주세요. |
| YouTube 가져오기 실패 | 공개 영상인지 확인하고 **세부 진행**의 오류를 보세요. 같은 영상을 로컬 파일로 갖고 있다면 **파일 열기**로 시도할 수 있습니다. |
| 해상도 부족 안내 | 더 높은 해상도의 영상이나 원본 파일을 사용하세요. |
| 흐리거나 엉뚱한 장면이 보임 | **악보 영역**에서 시점을 바꾸고 **현재 시점 다시 보기**를 누르세요. |
| 다음 단계로 진행할 수 없음 | 영상 준비가 끝났는지, **영역 적용**을 눌렀는지, 출력 형식을 하나 이상 골랐는지 확인하세요. |
| 음표나 기호가 잘림 | **악보 영역**으로 돌아가 범위를 넓혀 적용한 뒤 파일을 다시 만드세요. 이미 잘린 부분은 검토 화면의 자르기로 복구할 수 없습니다. |
| PDF에 제외한 캡처가 그대로 있음 | **PDF 다시 만들기**를 누른 뒤 새로 저장된 PDF를 여세요. |
| 보관함에 결과가 없음 | PDF를 만든 작업인지, 작업 폴더의 PDF를 옮기거나 지우지 않았는지 확인하세요. |

해결되지 않으면 [Issues](https://github.com/kr-ericshim/drum-score-capture-tool/issues)에 앱 버전, 운영체제와 CPU 종류, 사용한 입력(로컬 파일 또는 YouTube), 문제가 생긴 순서, 오류 메시지를 남겨 주세요. 로그에 개인 파일 경로나 비공개 링크가 있으면 지우고 올려 주세요.
