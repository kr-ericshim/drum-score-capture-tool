=== PRODUCT (unchanged) ===
A local Electron + Python app turns drum scores that are already shown in YouTube videos into printable A4 PDFs. No OMR, no transcription: we reuse source pixels. The user picks a region; the app samples frames, tracks each displayed system (page views, scrolling or jumping "jump views", cursors, overlays), builds one cleaned "strip" per system from many frames (median-like composite, cursor/overlay removal, per-member "minority content" check so ink seen in only some frames is never silently dropped), lays strips out on A4 in measure mode (cuts only at SAFE barline seams, ~4–6 measures per line, justified within caps), and writes a lossless PDF. User principle: notation near the staff (notes, accents, stems, beams, measure numbers, lyrics) must be kept at ~99.99 %; cosmetic leftovers are tolerated and must never mark a chart incomplete; noise that overlaps or imitates notation and duplicated measures are defects.
