## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| export metadata input -> renderer state -> job payload | user-entered strings and BPM values cross from UI input into a persisted job contract |
| stored export options -> review re-export | stale or partial stored options could make the reviewed PDF diverge from the original confirmed metadata |

## STRIDE Threat Register

| T-01-02 | D | `backend/app/main.py` export option reuse | mitigate | Read `document_header` from stored `job.options["export"]` in both `_run_job()` and `review_export()` and extend runtime/backend tests so stale or review-only payload paths cannot reappear. |
</threat_model>
