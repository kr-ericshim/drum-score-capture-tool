- **공통:** PDF 고지 경로에 `SHORT_DISPLAY`, `MINORITY_CONTENT_DROPPED`, `OVERLAY_UNRECOVERED`가 연결되어 있지 않다. 이 issue를 붙여도 페이지 raster가 byte 단위로 같다(repro `F07b`).

  - (b) 제외는 유지하고 PDF 머리말에 "검토 목록에 빠진 화면 N개"를 적는다.
  - (c) 현행 유지.
- 메모리 "notes-over-cosmetics"에 비추면 (a)나 (b)가 맞아 보인다. 다만 고지가 너무 많아지지 않는지 먼저 코퍼스로 세어 봐야 한다.
